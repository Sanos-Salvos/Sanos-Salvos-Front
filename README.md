# Sanos-Salvos-Front

Interfaz de usuario desarrollada en React con mapas Leaflet

## Puerto

3000

## Base de datos

Sin base de datos propia - interfaz React que consume la API del BFF

## Endpoints disponibles

Acceso web en http://localhost:3000

## Ejecucion con Docker

docker-compose up --build

## Ejecucion manual

mvn spring-boot:run

## Tecnologias

- Java 21
- Spring Boot 3.2
- Spring Security + JWT
- PostgreSQL
- Docker
